# M3-02 TEST-028 双平等 Agent 自主交付链路设计

## 1. 规范背景与目标

依据《AETP-设计方案.md》§§1.1、15.1、18.3：
TEST-028 的通过条件是：
1. **用户只提供粗糙想法**（Human Intent）：human_owner 提供粗糙想法与 Mission 目标，不人工拆细任务；
2. **两名以上平等 Agent 互相回应与协商**（Equal Agents without Manager）：平等成员在消息总线上讨论方案并达成共识，无 Manager 必经路径，无隐藏主 Agent 代替讨论；
3. **自主提出 Team 与 Blueprint（含 Task DAG）**：基于讨论形成版本化方案，包含角色能力绑定、任务依赖校验与循环检查；
4. **按方案执行与质量门控**：独立认领、交付产出物、同行评审与受信任验证；
5. **集成面任务通过 Integration Gate**：经历声明、基线校验合并、系统验证；
6. **Mission 逐条验收与交付**（TEST-010 / INV-019）：逐条验证 success_criteria 为 PASSED，由 human_owner 终验完成交付；
7. **全流程确定性重放**（Deterministic Event Replay）：从 SQLite Event Store 读取全部事件并重建状态，保证事实链不可篡改。

## 2. 架构设计与状态流转

```text
Human Intent (Rough Idea)
        │
        ▼
   Mission.propose (a-1) ───► Peer Discussion (a-1 <-> a-2 via MessageBus)
        │                                  │
        ▼                                  ▼
   Mission.activate (human_owner)     Team & Blueprint Proposals (Task DAG)
        │                                  │
        └─────────────────┬────────────────┘
                          ▼
              Task Execution & Quality Gate
                          │
                          ▼
                   Integration Gate
             (ready -> merge -> integrated -> system_verified)
                          │
                          ▼
              Mission Acceptance Gate
             (acceptance_start -> verify criteria -> complete)
                          │
                          ▼
              Deterministic Event Replay
```

## 3. 验收标准映射

- `test_028_criterion_01` (Human Intent & No Manual Decomposition): 人类只投入粗糙想法并激活，不人工拆细任务；
- `test_028_criterion_02` (Equal Peer Discussion without Manager): 两名平等 Agent 通过消息总线互相回应，无 Manager 参与或特权审查；
- `test_028_criterion_03` (Autonomous Team & Blueprint DAG): 平等 Agent 自主提出 Team 和 Blueprint，完成 Task DAG 循环依赖与版本核验；
- `test_028_criterion_04` (End-to-End Acceptance & Replay): 任务与 Mission 逐条验收通过，事件全流程确定性纯重放一致。

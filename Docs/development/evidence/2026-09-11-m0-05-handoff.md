## 行为与边界

1. `RuntimeRecovery.open` 用 SQLite `mode=ro` 打开已有事实文件，缺库/缺必要事实表/损坏文件明确失败；不创建目录、不建表、不迁移或修复 cache。
2. `rebuild_project` 强制读取完整 Event 流并纯重建；即使 cache 自带匹配摘要，也不作为恢复真相。
3. `reconcile_pending` 在同一只读快照读取 Command/Event，核对 identity、causation、type、digest、correlation、target 和 M0 终态类型；断链/矛盾拒绝。仅返回按 receipt sequence 排序的待核对 Command IDs，不执行、不授权、不修复结果索引。
4. receipt-only 为明确标记的人工存储故障夹具；当前 M0 Handler 同事务提交 receipt/领域或 rejected 事实/结果，不存在被此夹具暗示的正常半提交窗口。
5. 模拟计数来自真实调用，结果标记 `simulation-only`，不写入事实或幂等结果、不充当协议 ACK；恢复路径不调用模拟器。
6. 真实子进程在 Event 和原结果提交后被父测试进程终止，未向客户端返回响应；独立 witness 仅供断言。新连接重试原 Command/原 key，得到相同结果且无第二个领域效果。
